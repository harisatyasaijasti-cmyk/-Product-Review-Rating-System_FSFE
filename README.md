4. Abstract

The Product Review & Rating System is a web application that helps users share and view honest opinions about products. Before buying a product, customers often want to know what other users think about it, but this information is usually scattered or unorganized. In this system, users can browse a list of products, give a star rating from 1 to 5, write a review and view the reviews written by others. The system automatically calculates and displays the average rating for each product.

The application is built using HTML for the page structure, CSS for styling and layout, and Java for handling the review data and rating calculations. The main purpose of this project is to help users make better buying decisions through clear and organized product feedback.

5. Objectives

- To display a list of products with their details in an organized manner.
- To allow users to give a star rating (1 to 5) for a product.
- To allow users to write and submit reviews for products.
- To calculate and display the average rating of each product automatically.
- To display all reviews for a selected product.
- To allow users to sort and filter products by rating.
- To help users make better buying decisions using product feedback.
- To apply HTML, CSS and Java to a real-world problem.

6. Features

- User registration and login
- Product listing with name, category, price and description
- Star rating system (1 to 5 stars)
- Write, edit and delete reviews
- Automatic average rating calculation
- Display of total number of reviews for each product
- Sort products by highest or lowest rating
- Filter products by category or rating
- Validation to allow only one review per user per product
- Admin can add, update and remove products
- Simple and responsive user interface

7. Modules

User Module:
- Register and log in to the application.
- Browse the list of products.
- Give a star rating and write a review for a product.
- Edit or delete their own reviews.

Product Module:
- Displays all products with their details.
- Lets the admin add, update and remove products.
- Shows the average rating and total reviews for each product.

Review & Rating Module:
- Accepts the star rating and review text from the user.
- Validates the rating (1 to 5) and the review text.
- Makes sure a user can review a product only once.
- Calculates the average rating whenever a new review is added, edited or deleted.

Display Module:
- Displays all reviews for a selected product.
- Sorts products by rating.
- Filters products by category or rating.
